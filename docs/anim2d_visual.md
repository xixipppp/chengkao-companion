# anim2d 视觉与字幕规范（题目讲解类 2D 动画短视频）

> 版本：v1.0 · 设计稿 1080×1920（9:16）· 渲染方式：**canvas 2D 程序化绘制**
> 适用：`chengkao-companion`「成考专升本备考伴侣」三科（pol 政治 / eng 英语 / math 高数二）
> 硬约束：不引入外部图片、不用 webfont、不写 CSS 动画、不用 SVG filter —— 一切元素必须可用 `CanvasRenderingContext2D` API 画出。

---

## 0. 全局渲染约定（先读这一节）

### 0.1 设计稿坐标系统

所有规范数值均以 **1080×1920 设计稿坐标**给出。渲染时统一做一次缩放变换，业务代码里**只允许写设计稿坐标**：

```js
// canvas 实际像素 = 容器 CSS 宽 × DPR
const W = 1080, H = 1920;
const cw = Math.round(canvas.clientWidth * dpr);
const ch = Math.round(canvas.clientHeight * dpr);
canvas.width = cw; canvas.height = ch;
const s = cw / W;                       // 9:16 容器下 = ch / H
ctx.setTransform(s, 0, 0, s, 0, 0);     // 之后全部用 1080×1920 坐标绘制
```

- 竖屏容器必须 `aspect-ratio: 9/16`，否则按 `scale = min(cw/W, ch/H)` 并居中偏移（letterbox 用 `--bg:#0c0814` 填充）。
- DPR 上限锁 `Math.min(devicePixelRatio, 2)`，避免 3x 屏掉帧。

### 0.2 字体栈与字重（重要）

```
-apple-system,"PingFang SC","Microsoft YaHei",sans-serif
```

canvas 字体串写法（**字重必须用数字，且只用 400 / 700**）：

```js
const FONT = '-apple-system,"PingFang SC","Microsoft YaHei",sans-serif';
const f  = (size, weight=400) => `${weight} ${size}px ${FONT}`;
ctx.font = f(64, 700);
```

> ⚠️ **字重红线**：Windows 的「微软雅黑」只有 400 / 700 两档，`500/600` 会被回退成 400，导致 Mac / Windows 视觉不一致。
> 因此本规范**只使用 400 与 700**：需要"中等强调"时改用**加大字号 + 提亮颜色 + 加描边**实现，不要写 500/600。

### 0.3 每帧渲染循环

```js
function loop(now){                       // now = performance.now()
  const t = now - t0;                     // 毫秒，所有动效以 t 为唯一时间基准
  drawBackground();                       // 离屏缓存，drawImage 一次
  drawStage(t);                           // 舞台区（按时间轴调度场景）
  drawFixedChrome(t);                     // 固定元素：角标/字幕条/进度/水印
  requestAnimationFrame(loop);
}
```

- **禁止用帧计数驱动动画**（不同设备 30/60/120fps 会变速），一律用 `performance.now()` 差值。
- 背景层（渐变 + 径向光晕 + 暗角）**离屏 canvas 缓存一次**，每帧 `drawImage` 复用；只有科目切换时重建。

### 0.4 必备工具函数（规范依赖，实现时先落地）

| 函数 | 用途 | 要点 |
|---|---|---|
| `rr(ctx,x,y,w,h,r)` | 圆角矩形路径 | 手动 `moveTo/arcTo`（`ctx.roundRect` 兼容兜底），`r` 上限 `h/2` |
| `E.linear/outCubic/outQuint/inOutCubic/outBack/outElastic` | 缓动 | 见 §5.1 |
| `outlined(ctx,text,x,y,{fill,size,weight,lw})` | 描边文字 | **先 `strokeText` 后 `fillText`**，见 §3.3 |
| `wrap(ctx,text,maxW)` | 中文换行 | 用 `Array.from()` 逐字 + `measureText` 累加，禁止按字节截断 |
| `theme(subject)` | 三科主题色 | 见 §2.1 |

g.addColorStop(1.00, '#0a0612');

### 3.2 行高与段落

- 行高一律取 **8px 整数倍**（113→112、67→64/72 取 8 倍数微调）：H2 用 84、B1 用 72、S1 用 88。
- 段间距 = **0.6 × 行高**（H2 段间 48px，B1 段间 40px）。
- 字距：角标类 `ctx.letterSpacing = '2px'`（不支持时手动逐字绘制，或忽略）。

### 3.3 ★ 字幕样式（团队硬规范：字号加大一号 + 黑色描边）

**"加大一号"的定义**：字幕相对同屏正文（题干 H2 = 56px）**提升一档到 64px**，且字重 700。

```js
function drawSubtitle(ctx, text, cx, cy, opt = {}) {
  const size   = 64;                 // 加大一号：56 → 64
  const weight = 700;
  const lw     = 8;                  // 描边宽度 = 字号 × 12.5%
  ctx.font = `${weight} ${size}px ${FONT}`;
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  ctx.lineJoin = 'round';
  ctx.miterLimit = 2;

  // ① 外层柔光描边（可选，压住亮/杂背景）
  ctx.lineWidth = lw + 6;
  ctx.strokeStyle = 'rgba(0,0,0,.55)';
  ctx.strokeText(text, cx, cy);

  // ② 主黑色描边（硬规范）
  ctx.lineWidth = lw;
  ctx.strokeStyle = '#000000';
  ctx.strokeText(text, cx, cy);

  // ③ 填充（先描边后填充，描边向外扩不侵蚀字面）
  ctx.fillStyle = opt.color || '#f3ecff';
  ctx.fillText(text, cx, cy);
}
```

**关键红线**

1. **绘制顺序必须是 `strokeText` → `fillText`**，顺序颠倒会让描边吃掉字形，字变细。
2. `lineJoin='round'` + `miterLimit=2`：避免中文尖角产生"毛刺"长角。
3. 描边宽度 = `字号 × 0.125`（64px → 8px；H0 96px → 12px；角标 32px → 4px）。**最小不低于 4px**。
4. 高亮关键词：**描边不变（仍纯黑）**，只改 `fillStyle` 为 `#ffd166` 或科目 primary，并额外加 1 层 4px 黑描边做"色块隔离"。
5. 字幕底板（背景杂乱时启用）：`rr(72, 1478, 936, 232, 28)`，`fillStyle='rgba(12,8,20,.72)'`，内边距左右 28 / 上下 20。
6. 字幕**永不换行超过 2 行**；单行 ≤ **14 个汉字**（`936 / 64 ≈ 14.6`）。
7. 高对比兜底：任何情况下字幕文字与紧邻背景的对比度 ≥ **7:1**。

## 5. 关键动效清单（MG 动画）

### 5.1 缓动函数（canvas 内实现）

```js
const E = {
  linear      : t => t,
  outCubic    : t => 1 - Math.pow(1 - t, 3),
  outQuint    : t => 1 - Math.pow(1 - t, 5),
  inOutCubic  : t => t < .5 ? 4*t*t*t : 1 - Math.pow(-2*t + 2, 3) / 2,
  inOutQuint  : t => t < .5 ? 16*t*t*t*t*t : 1 - Math.pow(-2*t + 2, 5) / 2,
  outBack     : (t, s = 1.6) => 1 + (s + 1) * Math.pow(t - 1, 3) + s * Math.pow(t - 1, 2),
  outElastic  : t => t === 0 ? 0 : t === 1 ? 1
                 : Math.pow(2, -10 * t) * Math.sin((t * 10 - .75) * (2 * Math.PI / 3)) + 1,
};
// 采样：const p = E.outCubic(clamp((t - start) / dur, 0, 1));
```

### 5.3 动效调度建议

- 单个场景内**同时运行的动效 ≤ 3 个**（性能与注意力双限）。
- 默认节奏：题干 `typewriter` → 停顿 **400ms** → 选项 `cardFlyIn` → 判定 `correctPulse`/`wrongShake` → 解析 `fadeUp` → 字幕推进。
- 全部时长用「**总时长预算**」反推：60s 视频 ≈ 4 题 × 12s（片头 2.4s + 每题 ~12s + 结尾 3s）。

## 7. 可读性红线

### 7.1 字号下限

| 类型 | 最小字号 | 说明 |
|---|---|---|
| 绝对最小 | **26px** | 仅限水印 / 时间码 |
| 正文最小 | **40px** | 解析位、选项内小字不得低于 40 |
| 字幕 | **64px**（加大一号） | 低于此值视为违规 |
| 卡片内文字 | **48px** | 选项文本硬性下限 |

### 7.2 对比度（WCAG AA 及以上）

| 前景 | 背景 | 比值 | 结论 |
|---|---|---|---|
| `#f3ecff` | `#0c0814` | ≈ 17:1 | ✅ 正文首选 |
| `#f3ecff` | `#1c1430`（卡片） | ≈ 13:1 | ✅ 选项/题干 |
| `#b6a6e0` | `#1c1430` | ≈ 6.5:1 | ✅ 次级文字 |
| `#7c6ca8` | `#1c1430` | ≈ 3.1:1 | ❌ **禁止作正文**，仅禁用态/装饰 |
| `#ffd166` | `#0c0814` | ≈ 11:1 | ✅ 金色强调 |
| `#5be3a7` / `#ff7a9c` | `#0c0814` | ≈ 9:1 / 7:1 | ✅ 判题色 |

- **任何文字下方不得有高亮粒子/亮色块直接穿过**；必要时启用字幕底板（§3.3-5）。
- 描边黑 `#000000` 对亮色背景提供 ≥ 4.5:1 的字形边界隔离。

### 7.3 单屏最大文字量

| 区域 | 上限 |
|---|---|
| 题干（C1） | **3 行** × 56px（≤ 42 字，含标点） |
| 选项卡 | **4 张**，每张 ≤ 2 行 × 48px（≤ 24 字/张） |
| 解析位（C3） | **2 行** × 44px（≤ 40 字） |
| 字幕区 | **2 行** × **14 字**（≤ 28 字） |
| **同屏可见汉字总量** | **≤ 90 字**（超出即拆成两个场景） |

### 7.4 中英混排处理

1. 中英文/数字之间插入 **1/4 空格**（`U+2005`，或直接 `ctx` 逐段绘制时加 `0.28em` 间隙）。例：`泰勒公式 Taylor formula` → `泰勒公式 Taylor formula`（间隙 18px @64px）。
2. 数字与单位之间 **0.25em**：`60 分`、`2024 年`。
3. **换行按字符切分**：`Array.from(text)`，禁止 `substring(byteIndex)` 截断（会切坏 emoji / 代理对 / 英文单词）。
4. 英文单词**不内断**：换行检测时对连续 ASCII 段整体 `measureText`，宽度超限时整词下移。
5. 标点避头尾：`。，、；：！？》）」` 不得出现在行首；`《（「` 不得出现在行尾。
6. **正文禁用 emoji**；粒子/装饰可用几何图元代替。
7. canvas 中 `textAlign='center'` + 混排时，先 `measureText` 总宽再居中，避免视觉偏移。

### 7.5 其他红线

- 舞台元素不得进入 `y > 1450`（字幕区）与 `y > 1800`（禁放区）。
- 重要交互元素不得进入 `x > 940`（平台点赞栏遮挡带）。
- 纯亮色（`#ff7a9c` / `#5ee0f0` / `#b794ff` 满饱和）**作背景面积 ≤ 屏幕 20%**，仅作描边、胶囊、CTA 填充。
- 同屏高亮色 ≤ 2 种；动画同时运行数 ≤ 3。
- 每帧 `save()/restore()` 必须配对；`shadowBlur` 用完立即置 0（否则污染后续绘制且极耗性能）。
